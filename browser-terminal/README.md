# CB Round Terminal — Browser Demo

A standalone HTML/CSS/JavaScript mock terminal designed for mobile Chrome. It includes target input, time presets, start/stop, countdown, status, a local demo value, and minimize behavior.

## Run it
Open `index.html` in a browser or serve this folder from a static host. No build step or Android app is required.

## Important limits
This is a local UI/timer demo only. It does not connect to Quotex, intercept broker WebSocket traffic, change live chart prices, or execute trades. A matching UI is feasible; reproducing third-party live-chart behavior requires an authorized API or test environment and cannot be assumed from appearance alone.
