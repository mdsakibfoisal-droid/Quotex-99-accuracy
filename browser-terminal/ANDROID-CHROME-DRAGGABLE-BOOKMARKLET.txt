Quotex floating voice helper — Android Chrome bookmarklet
==========================================================

This bookmarklet adds a draggable Q99 bubble on the CURRENT webpage and a voice-only Bengali interface. It uses the browser's Web Speech API when available. It does not connect to an AI service, read protected live candle data, or place trades.

INSTALL
1. Create a Chrome bookmark and name it "Q99 ভয়েস সহকারী".
2. Edit the bookmark and replace its URL/address with the COMPLETE single line below.
3. Open https://market-qx.info/en/trade and wait for the chart to load.
4. In Chrome's address bar, type the bookmark name and tap the saved bookmark suggestion.
5. Tap the Q99 bubble. Tap "🎙 কথা বলুন" to start voice recognition; tap "⏹ বন্ধ" to stop.

LIMITS
- Voice recognition depends on Chrome/Web Speech API support, microphone permission, and sometimes an internet connection.
- The voice responses are limited, predefined responses, not an AI conversation.
- It cannot read protected/cross-origin chart data, reliably derive OHLC from the chart canvas, or float over other tabs/apps.
- No live CALL/PUT signal, accuracy guarantee, or automated trade placement is included.
