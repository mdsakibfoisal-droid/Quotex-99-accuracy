# Md Jibon Quotex 99%

Md Jibon Quotex 99% is an Android trading automation app designed around pattern recognition and automated trade execution for Quotex.

## Features
- Floating icon overlay for scanning control
- Blue overlay scan feedback
- MediaProjection-based screen capture
- Pattern detection and comparison engine
- Market detection support
- Local trade logging and history
- Settings screen and notification toggle
- Accessibility service automation

## Android project setup
- Kotlin
- Android SDK 34
- Min SDK 26
- Target SDK 34
- Gradle 8.x

## Build
```bash
./gradlew assembleRelease
```

## Notes
This repository contains the initial Android project skeleton and core app modules for the proposed app under the `Quotex-99-accuracy` repository.
